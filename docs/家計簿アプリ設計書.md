# 家計簿アプリ設計書

-   **プロジェクト名**：Household Account Book
-   **バージョン**：1.0.0
-   **作成日**：2026-08-05
-   **開発環境**：React + TypeScript + Next.js (App Router)

## 概要

収入・支出を登録し管理する家計簿アプリ。

### 学ぶ内容

-   useEffect
-   LocalStorage
-   フォーム入力
-   複数State管理
-   データ集計
-   Component設計

## 画面

-   家計簿一覧画面（1画面）

## 機能

1.  収支追加
2.  削除
3.  一覧表示
4.  収入集計
5.  支出集計
6.  収支計算
7.  LocalStorage保存
8.  LocalStorage読込
